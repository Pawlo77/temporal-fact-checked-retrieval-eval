## What it does

- Task 1: source retrieval for scientific web claims (follow-up of 2025).
- Task 2: fact-checking numerical and temporal claims, adding a reasoning component.
- Task 3: generating full fact-checking articles.
- Lab held at CLEF 2026, Jena, 21-24 September 2026; site programme lists Task 1-3 overview talks and a "What's next on CheckThat!" slot.
- CheckThat! 2025 (checked via the CLEF 2025 lab page and the Springer overview abstract): Task 1 subjectivity, Task 2 claim normalization, Task 3 numerical claims, Task 4 scientific web discourse.

## Relation to our project

- No PFCR task in 2025 or 2026, so there is no live lab task to collide with; a temporal PFCR task remains a proposal option.
- Task 2's numerical/temporal claim verification is about claim content with time expressions, not about time-restricted retrieval of fact-checks.
